# ADR-014 — Independent watchdog architecture

**Status:** Accepted Phase 0 design; emergency channel/provider/recipients OWNER-04 unresolved.

**Context:** Normal Ada and its notification queue cannot reliably announce their own outage.

**Decision:** Use a DB-host watchdog outside normal execution and an external monitor outside
the primary host. Give emergency alerts an independent path; monitor the watchdog itself.

**Rationale:** Independence removes shared failure dependencies and false health from run strings.

**Alternatives considered:** More Task Loop polling; status dashboard alone; normal outbox-only alerts.
They all depend on mechanisms that may already have failed.

**Consequences:** Define heartbeat/flow SLAs, dedupe and recovery evidence; test actual notification
delivery later. No emergency recipient or standing send authorization is invented in Phase 0.

**Portability impact:** Monitoring can run outside any chosen database/AI host.

**Acceptance implications:** WATCH-01 proves a real alert after heartbeat suppression and host outage.
Mock alerts do not constitute E2E verification of this boundary.
