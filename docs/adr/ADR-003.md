# ADR-003 — No dual-master authority

**Status:** Accepted Phase 0 design; cutover window/thresholds OWNER-06 unresolved.

**Context:** Shadow comparison can accidentally produce duplicate business/provider effects.

**Decision:** Exactly one authoritative writer per business fact/effect. 1.x remains current
authority; later shadow work is explicitly nonauthoritative and cannot duplicate effects.

**Rationale:** Bidirectional writes would create ambiguous completion, identity and delivery state.

**Alternatives considered:** Dual writes with later merge; provider-level dedupe as sole protection.
Neither resolves conflicting business authority or unknown send outcomes.

**Consequences:** Rehearsed delta import, freeze, reconciled switch and rollback; a restored copy
does not acquire authority merely by being available. No shadow database in Phase 0.

**Portability impact:** Authority is a documented governance switch independent of host/platform.

**Acceptance implications:** Migration/cutover gates prove one writer and reconciled evidence;
MIG-02 plus later signed cutover runbook. No live writes in the default test suite.
