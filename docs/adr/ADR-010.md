# ADR-010 — AI Memory remains governed semantic continuity

**Status:** Accepted Phase 0 design.

**Context:** Replacement AI needs semantic continuity beyond raw business rows, but memory cannot
outrank current structured authority or become a hidden operational database.

**Decision:** Keep scoped records, immutable versions, explicit supersession, provenance,
effective date, retention/sensitivity, authoritative references, hash and compaction manifest.
Activate one head atomically per scope/kind; deliver scoped bootstrap packages.

**Rationale:** Continuity can be durable, auditable and portable while respecting source precedence.

**Alternatives considered:** Conversation history only; overwrite rolling text; remove memory.
These lose recovery context, provenance or immutable history.

**Consequences:** Validate contradictions and retrieval before head activation; preserve legacy
MEM-ECOS-000036 alias without assuming review-time v94 is still current.

**Portability impact:** Ordinary versioned records and package schemas replace product memory lock-in.

**Acceptance implications:** MEM-01 head concurrency/immutability and PORT-01 bootstrap without
conversation; sensitivity tests include references and unresolved exceptions.
